ON YOUR COMPUTER

One app.
Two ways to work.

Use the connected workspace for the full toolkit, or native tools for larger files. Both run locally, without an account or cloud conversion.

Connected workspace

All 22 workspace tasks are included: Word and PowerPoint previews to PDF, text/PDF/data conversion, image tools, PDF compression and splitting, HEIC conversion, OCR, document scanning and screenshot design. Pass a result straight to the next compatible tool.

Engines, fonts, the background model and English, German and Turkish OCR data are bundled. There is no offline pack to download and no runtime CDN request. The workspace uses the same practical limits as the browser tools.

Files and results stay in the current page’s memory. Download results before navigating away or closing FileForge. Clear all releases the workspace’s selection and previews. Optional favourites/settings contain tool choices, not selected documents, and the private window clears its storage when the app closes.

Office exports are flattened page images. Layout and fonts may differ from Microsoft Office; check the preview. DOC/PPT, macros and embedded objects are not supported. OCR exports text; it does not make a searchable PDF.

Native tools

The nine existing native converters remain available, including larger video, image and PDF jobs. They run through a service bound only to 127.0.0.1, which means this computer. Workspace file limits and native file limits differ; each tool shows its own limits.

Native tools copy selected inputs into temporary job folders on this computer. Source copies are deleted after completion, failure or cancellation. Results expire after 24 hours while the app is running; old folders are cleaned at startup. Clear completed removes retained native results. Downloaded files stay where you saved them.

Native video compression needs separately installed FFmpeg and FFprobe on PATH. The workspace’s short-video engine is bundled and does not need that installation. Microsoft Edge WebView2 is required for the application window.

Downloads and updates

Keep FileForge.exe and the workspace folder together. Download and extract the complete release, then use install.cmd or run the executable directly. Updating the website does not silently change this installed app; a desktop update replaces its tested workspace and native executable.

The workspace folder contains ordinary replaceable engine files, licenses and a pinned source manifest. Read component notices or view source and build references.
